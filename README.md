# Cat Dog Battle

《猫狗大战》Godot 4 原型项目。

当前版本先验证第一版核心玩法：

- 3v3 萌宠道具拆家竞技
- 玩家控制 1 只宠物，另外 2 名队友由 AI 控制
- 对面 3 只宠物全部由 AI 控制
- 局内不做进化，只做抢道具、护送、拦截、炸家
- 局外已有最小“修整准备期”：选阵营、选宠物、金币奖励、宠物升级
- 二阶进化暂时只作为后续目标，不放进第一版局内规则

## 玩法规则

- 双方基地各有 5 点耐久。
- 地图中央刷新 `Boom Snack`。
- 把 `Boom Snack` 送进敌方基地，敌方基地耐久 -1。
- `Repair Can` 送回自己基地，可以恢复 1 点耐久。
- `Speed Bell` 拾取后短时间加速。
- `Shield Bone` 拾取后获得护盾。
- `Stinky Sock` 可以按 `E` 投掷，命中敌人后减速。
- 先把对方基地炸到 0 的队伍获胜。

## 操作

- 移动：`WASD` 或方向键
- 普攻：`J` 或鼠标左键
- 技能：`K` 或鼠标右键
- 丢下/投掷道具：`E`
- 结束后返回菜单：`Enter` 或空格

## 运行

1. 安装 Godot 4.x。
2. 用 Godot 打开本文件夹。
3. 打开后运行主场景 `scenes/Main.tscn`。

## 当前实现重点

这个版本不是正式美术版，而是可玩性验证版。宠物、基地、道具都用程序绘制，方便快速调规则。

当前垂直切片闭环：

```text
准备期选阵营/宠物 -> 进入 3v3 对局 -> 抢 Boom Snack 炸家 -> 胜负结算 -> 获得金币 -> 回准备期升级
```
